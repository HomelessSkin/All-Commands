Для добавления звуковых команд необходимо:
1. Клонировать этот репозиторий на своё устройство.
2. В папке "Sound Alerts/Commands" нужно разместить свой JSON файл по этому примеру:
``` JSON
{
    "IsPublic": true,           // Флаг говорит о том что команда может быть вызвана из чата.
    "IsFinal": true,            // Флаг говорит о том что после выполнения команды обработка сообщения должна прекратиться.
    "Priority": 0.0,            // Приоритет выполнения команды в случаях если в сообщении было найдено несколько ключей команд.

    // ПЕРВЫЕ ТРИ ПУНКТА ЛУЧШЕ ОСТАВИТЬ КАК ЕСТЬ БЕЗ КРАЙНЕЙ НЕОБХОДИМОСТИ В ОБРАТНОМ
   
    "Input": {                  // Объект класса Ввода который будет вызван при обнаружении ключей команды
        "Title": "Sound Alert", // Для воспроизведения звуковой команды поле "Title" должно быть "Sound Alert"
        "ID": "",
        "Source": "Message",    // Источник вызова для дебага в консоли
        "Agent": "Chatter",     // Сюда, при желании, можно написать свой ник. Когда-нибудь он будет выводиться на экран при обнаружении ключей команды
        "Message": "",          // Это поле перезаписывается при отправке Ввода и содержит ссылку на звуковой файл
        "Point": 0,             // Здесь не используется
        "Spawn": 0              // Здесь не используется
    },
   
    "Folder": "Sounds",         // Папка содержащая звуковой файл
    "Keys": [                   // Список ключей.
        {
            "Cuts": [           // Объект ключа содержит список "Cuts" (ключевых слов). Максимальное количество слов внутри одного ключа - 7
                "страшно",
                "ужас"
            ]
        },
        {
            "Cuts": [          // Ключей может быть неограниченное количество.
                "aaaa"         // Т.о. для вызова одного и того же звукового файла,
            ]                  // либо одного из списка звуковых файлов,
        }                      // могут быть использованы разные ключи
    ],
    "Clips": [                 // Список звуковых файлов для воспроизведения. При добавлении нескольких файлов - во время обработки вызова выбирается случайный файл
        {                      // Объект звука содержит поля громкости и имени файла расположенного в папке указанной в поле "Folder" выше
            "Volume": 0.5,     // Громкость воспроизведения от 0.0 до 1.0
            "Path": "aaaa"     // Имя звукового файла
        },
        {
            "Volume": 0.5,     // Громкость воспроизведения от 0.0 до 1.0
            "Path": "bbbb"     // Имя звукового файла
        }
    ]
}
```

3. В соответствующей папке разместить все звуковые файлы указанные в команде.
4. Опубликовать запрос на внесение Ваших изменений и дождаться решения. Если стрим идёт - лучше написать в чате о запросе.
